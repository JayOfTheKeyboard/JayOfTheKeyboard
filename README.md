I'm Jeremy, a developer in Australia. I write mostly Go and Rust, and I'm a little obsessed with making software fast and lean.

My interests wander: tools for AI coding agents, running AI locally, IT admin tools, peer-to-peer networking, security and bug hunting. Most of my public work so far is fixes in other people's projects, listed below. The tools I build myself are released under [Sigilet Labs](https://github.com/sigiletlabs).

By day I look after systems and infrastructure, and manage open source projects, for a not-for-profit. Everything here is personal work.

If you work on similar things, I'd like to hear from you. Open an issue on any of my repos and say hello.

## Start here

- [soc-thief](https://github.com/sigiletlabs/soc-thief): sleep through the night while it reads your Wazuh alerts. You get one Discord message in the morning, and a page only when something looks like a breach. An AI model gives advice but can't hide an alert. It runs on your own host, reads Wazuh with a read-only account, and sends nothing to a hosted model unless you opt in.

  <a href="https://github.com/sigiletlabs/soc-thief"><img src="https://raw.githubusercontent.com/sigiletlabs/soc-thief/main/docs/images/globe.gif" alt="The soc-thief console's globe view: a rotating terminal globe, locked on Australia, with attack arcs flying in from other countries and a red breach banner at the end" width="640"></a>

- [ai-quota-meter](https://github.com/sigiletlabs/ai-quota-meter): shows your remaining Claude Code quota on the status line, using Anthropic's own numbers, and switches on Codex's built-in quota display. A single static binary with no network access.
